# Diamonds Predictor Capstone Project

This project uses the Diamonds dataset to practice data analysis and machine learning in Python.

## Project Overview

In this project, I worked with the `diamonds.csv` dataset. I explored the data, cleaned it, prepared it for machine learning, built models, created a simple assistant, and compared the results.

## Project Steps

- Step 2: Data collection and basic dataset inspection
- Step 3: Exploratory data analysis with plots and summary files
- Step 4: Data preprocessing and feature engineering
- Step 5: ANN classification model for diamond clarity
- Step 6: Simple diamond question-answer assistant
- Step 7: ANN regression model for diamond price prediction
- Step 8: K-Means customer segmentation
- Step 9: Model comparison and evaluation

## Libraries Used

- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

## Dataset

The dataset file is:

`diamonds.csv`

It should be in the main project folder.

## How to Run

Run the Python files in order from Step 2 to Step 9.

Each step saves its own outputs inside its own folder.

## Note

Step 6 uses a local dataset-based assistant instead of the OpenAI API because the OpenAI API requires separate billing and credits.
