Step 5 - Build the Classification Model

In this step, I built an Artificial Neural Network model to classify diamond clarity.
I used the prepared classification training and testing files from Step 4.
The target column for this model is clarity_encoded.

Training data shape:
(43136, 21)

Testing data shape:
(10784, 21)

Model structure:
Input layer based on the number of features
Hidden layer with 128 neurons and relu activation
Hidden layer with 64 neurons and relu activation
Hidden layer with 32 neurons and relu activation
Output layer with softmax activation

Evaluation results:
Accuracy: 0.6151706231454006
Precision: 0.6125152326769824
Recall: 0.6151706231454006
F1-score: 0.6133300569055228

Business interpretation:
This model can be used to estimate the clarity category of a diamond based on its features.
This can help organize diamond information and support pricing or product analysis.
The confusion matrix is useful because it shows which clarity groups the model predicts well and which groups it mixes up.
The training and validation plots help me check whether the model is learning properly or overfitting.
