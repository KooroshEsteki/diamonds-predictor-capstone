Step 7 - Build the Regression Model

In this step, I built an Artificial Neural Network model to predict diamond prices.
I used the prepared regression training and testing files from Step 4.
The target column for this model is price.

Training data shape:
(43136, 28)

Testing data shape:
(10784, 28)

Model structure:
Input layer based on the number of features
Hidden layer with 128 neurons and relu activation
Hidden layer with 64 neurons and relu activation
Hidden layer with 32 neurons and relu activation
Output layer with 1 neuron for price prediction

Evaluation results:
MAE: 327.98272705078125
MSE: 1017340.6875
RMSE: 1008.6330787258565
R2: 0.9365429282188416

Business interpretation:
This model can be used to estimate the price of a diamond based on its features.
MAE and RMSE show the average size of the prediction error in dollars.
R2 shows how much of the price variation is explained by the model.
The scatter plot with the ideal line helps show how close the predicted prices are to the real prices.
The comparison plot shows actual and predicted prices for the first 200 test samples using both lines and markers.
